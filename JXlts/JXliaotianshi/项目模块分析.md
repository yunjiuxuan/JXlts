### 1.2 UserInfo 结构体

```cpp
struct UserInfo {
    int id;              // 用户ID (数据库主键)
    QString username;    // 登录用户名 (唯一标识)
    QString nicheng;     // 昵称 (显示名)
    QString ip;          // IP:Port 如 "192.168.1.100:8888"
    int status;          // 0=离线, 1=在线
    QByteArray touxiang; // 头像数据
};
```

> **关键**: 群聊记录 `username=""`(空)，普通用户 `username` 有值。

### 1.3 数据库表: userinfo

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INTEGER PRIMARY KEY AUTOINCREMENT | 自增主键 |
| `username` | TEXT | 登录名 (群聊为空) |
| `password` | TEXT | MD5加密密码 |
| `ip` | TEXT | 局域网IP:端口 |
| `touxiang` | BLOB | 头像数据 |
| `nicheng` | TEXT | 昵称 |
| `status` | INTEGER DEFAULT 0 | 0=离线, 1=在线 |

### 1.4 JSON消息协议

```json
{
    "sender_id": 3,        // 发送者用户ID
    "target_id": 4,        // 目标用户ID
    "content": "你好",      // 消息内容 (文件或握手时含义不同)
    "type": 0,             // 消息类型: 0=握手, 1=文件头, 2=文件数据, 3=取消, 10=群消息, 其他=文本
    "timestamp": "2026-05-28 09:00:00",
    "file_size": 12345     // type=1时存在，文件大小
}
```

### 1.5 TCP消息帧格式

```
[4字节 qint32 消息体长度][变长 JSON 字符串]
```
使用 `QDataStream` 序列化和反序列化。

### 3.5 接收数据与消息处理 (onSocketReadyRead)

**文件**: `userhome.cpp:525`

```
socket 收到数据 (readyRead 信号)
  │
  ▼
1. 读取新数据: QByteArray newData = socket->readAll()
2. 追加到缓冲区: m_socketBuffers[socket].append(newData)
3. 循环解析消息 (处理粘包):
   │
   ├── 检查缓冲区 >= 4字节 (消息长度头)
   ├── 读取 qint32 blockSize (消息体长度)
   ├── 检查缓冲区 >= 4 + blockSize
   ├── 跳过长度头, 读取 JSON 字符串
   ├── 从缓冲区移除已处理的数据
   │
   └── JSON解析:
       ├── 获取 sender_id, target_id
       ├── 如果 sender_id > 0 且 socketId 是临时ID (>=10000):
       │   ├── 检查是否已存在该用户的连接 → 存在则关闭新连接
       │   ├── 否则更新映射: m_activeSockets[senderId] = socket
       │   ├── emit userConnected(socketId)
       │   └── emit groupStatusChanged(0)
       │
       ── 根据 type 字段分发处理:
           ├── type = "HANDSHAKE": 握手消息, 不显示
           ├── type = 1: 文件头
           │   ├── 创建接收目录: chat_logs/{自己id}_{对方id}/downfile/
           │   ├── 处理文件名冲突 (加后缀 _1, _2...)
           │   ├── 创建 QFile 对象
           │   ├── 存储到 m_receiveFileState[socketId]
           │   └── emit fileProgress(socketId, 0, fileSize)
           │
           ├── type = 2: 文件数据块
           │   ├── Base64解码
           │   ├── 写入文件: state.file->write(data)
           │   ├── 累加接收进度
           │   ├── emit fileProgress(socketId, received, total)
           │   ── 如果接收完成:
           │       ├── 关闭文件
           │       ├── 检测是否为媒体文件 (mp3/wav/mp4/avi等)
           │       ├── 如果是媒体文件:
           │       │   ├── 移动到 Media/ 子目录
           │       │   ├── INSERT INTO QMediaPlayer{id} (targetId, url) VALUES (...)
           │       │   └── emit mediaFileAdded(senderId, relativePath)
           │       ├── emit messageReceived(senderId, "文件接收成功通知")
           │       └── emit fileReceived(senderId, fileName, filePath)
           │
           ├── type = 3: 文件取消通知
           │   ├── 关闭并删除不完整文件
           │   ├── m_receiveFileState.remove(socketId)
           │   └── emit fileCancelled(socketId, fileName)
           │
           ├── type = 10: 群消息
           │   ├── 从 JSON 获取 group_id
           │   ├── 格式化: "[时间] 发送者昵称: 内容"
```

### 3.8 发送消息 (sendMessageToUser)

**文件**: `userhome.cpp:1101`

```
调用 sendMessageToUser(userId, message, messageType)
  │
  ▼
1. 检查 m_activeSockets 是否包含 userId
2. 检查 socket 是否 ConnectedState
```


### 3.10 文件发送进度 (onSocketBytesWritten)

```

       ├── 序列化并 socket->write()
       ├── bytesSent += data.size()
```


**注意**: 群消息 type=10, 发送时遍历所有在线用户, 通过已有的TCP连接逐个发送。消息不存文件(只存群聊日志文件), 只实时显示在打开的群聊窗口上。

### 3.18 群聊日志文件

| 函数 | 文件 | 说明 |
|------|------|------|
| `initGroupChatFile()` | `userhome.cpp:1780` | 登录时创建/清空 `群聊_{用户ID}` 文件 |
| `saveGroupMessageToFile(msg)` | `userhome.cpp:1806` | 收到群消息时追加写入 |
| `loadGroupMessagesFromFile()` | `userhome.cpp:1824` | 打开群聊窗口时读取历史 |
| `cleanupGroupChatFile()` | `userhome.cpp:1858` | 程序退出时删除文件 |

**文件路径**: `chat_logs/群聊_10` (用户ID=10)

### 3.19 程序退出流程

```
UserHome::closeEvent(QCloseEvent *event)
  │
  ▼
1. 关闭所有聊天窗口: m_chatWindows.values() → win->close()
2. 关闭所有TCP连接:
   ├── 遍历 m_activeSockets
   └── socket->disconnectFromHost()
3. 关闭TCP服务器: m_tcpServer->close()
4. 更新用户状态为离线: UPDATE userinfo SET status=0 WHERE id=:id
5. 删除群聊日志文件: cleanupGroupChatFile()
6. event->accept()
```

同时 `onApplicationQuit()` 也会在 `QApplication::aboutToQuit` 信号触发时执行类似操作(双重保障)。
